2. Hosting via GitHub Pages

This website is provided through GitHub Pages. When the site is requested, technically necessary connection data is transmitted to GitHub. GitHub documents processing including IP address, device and connection information, and the date and time of requests. GitHub Pages logs visitors' IP addresses for security purposes.

The purpose is the secure and reliable provision of this website. The legal basis is Art. 6(1)(f) GDPR (legitimate interest in operating, securing and protecting the website against misuse).

More information: GitHub General Privacy Statement.

3. External GitHub content

Some project images and screenshots are loaded directly from GitHub's raw-content domain. The browser therefore connects to GitHub when the page is opened. In particular, IP address, browser/device information and request time may be processed. The legal basis is Art. 6(1)(f) GDPR; the legitimate interest is presenting the publicly documented projects.

4. Local browser storage

The website does not use analytics or advertising cookies. The selected visual theme may be stored only in the visitor's browser. This setting is not transmitted to the site operator and is used only to provide the display selected by the visitor.

5. No analytics, advertising or forms

This portfolio does not use first-party analytics, advertising trackers, marketing pixels or contact forms. The operator does not create visitor profiles.

6. Free projects

The apps and projects presented on this portfolio are offered free of charge. No paid services are sold and no orders are processed through this website.

7. External links

Links to GitHub, Discord and individual project pages are requested only after they are clicked. The privacy policies of the respective external services apply after leaving this portfolio.

GitHub states in its privacy documentation that it participates in the EU-U.S. Data Privacy Framework. Where applicable to a particular transfer, this framework may provide a basis for transfers of personal data from the European Union to the United States.

Details about recipients, international transfers, safeguards and retention are provided in GitHub's current privacy statement.

9. Retention
