HIGHLIGHTS

Highlights

01

Verified backups

Preview selected sources, create portable packages and verify them with SHA-256 checks before restoring.

02

Safe restore

Restore selected sources into new folders, so existing files are never overwritten.

03

Local control

Backups stay on your chosen storage. The app does not upload data or run silent backups.

PRIVACY

Privacy

CodexVault works locally. Normal backups exclude typical secrets and build artefacts; complete Codex backups can contain sensitive local data and should only be stored in a trusted destination.
