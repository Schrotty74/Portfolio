NATIVE MACOS APP

ThermalAtlas

A local, read-only Apple Silicon temperature monitor for the macOS menu bar. It shows CPU, GPU, internal SSD and detected external SSD temperatures when macOS and the connected hardware expose a real sensor value.

HIGHLIGHTS

Highlights

01

Four sources

See CPU, GPU, internal SSD and a detected external SSD in one compact native panel.

02

Honest availability

A sensor without a real readable value is shown as unavailable, never estimated or invented.

03

Read-only by design

Temperature data refreshes locally every two seconds. ThermalAtlas does not control fans, power settings or other system settings.

PRIVACY

Privacy

There are no accounts, analytics, advertising, cloud services or telemetry. Sensor and drive information is read locally; temperature histories are not saved. The selected appearance is stored only in local app preferences.
