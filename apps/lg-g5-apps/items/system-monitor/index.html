Project description

A homebrew dashboard for the LG G5 running webOS 25, with a dark layout designed for TV screens.

AI-assisted development

Schrotty74 develops these projects with AI assistance and retains final review and responsibility.

Features and details

01CPU and RAM usage, with history charts for the last 30 readings
02Uptime, kernel, root status, model, firmware, SDK, and board information
03Filesystem free/used space with usage bars
04Active network interface, IPv4 address, and default gateway
05Snapshot of active processes and swap usage
06Refresh interval selectable between 3, 5, and 10 seconds
07Scrolling with the Magic Remote or mouse wheel; Back and Exit controls
08No temperature tile: no readable sensor value was found on the tested G5
09app/ contains the complete app source, including its icon
10Download the IPK
11Download the source ZIP
12Development notes: architecture, data sources, checks, current UI observation, and constraints for future work.
13Changelog: development history and user requirements by version.
