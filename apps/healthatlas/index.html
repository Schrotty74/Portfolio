THE APP

Understand your health data without handing it away.

HealthAtlas is a native macOS app for analysing an Apple Health export locally. You choose an Export.xml file or ZIP archive yourself, select the recognised data types you want to see, and explore them in a calm visual interface.

The focus is not raw tables or medical scoring, but understandable dashboards, time-based views, comparisons and descriptive patterns. HealthAtlas starts without personal data and opens empty again for the next session.

PRIVACY

Personal health data stays local.

HealthAtlas is designed around local processing. It is a tool for exploring your own recorded data, not a medical diagnosis or treatment recommendation.

No health-data cloud

Imported health data stays in memory for the current session and is not uploaded to a HealthAtlas server.

No accounts or trackers

The project contains no accounts, advertising, analytics or tracking.

No direct HealthKit connection

HealthAtlas reads only the local Apple Health export you select.

Optional release check

When enabled, only the public GitHub release list is requested; health data is never included.
