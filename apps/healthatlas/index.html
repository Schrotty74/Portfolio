What it does

HealthAtlas imports an Apple Health Export.xml file or ZIP archive that you select and turns selected data types into local visual trends. Instead of presenting a diagnosis, it provides configurable cards, timelines, ranges and pattern views to help you explore your own recorded data. It starts empty and returns to an empty state after the session.

AI-assisted development

Developed by Schrotty74 with AI assistance. Depending on the project, OpenAI Codex and, in parts, Claude supported development work; Xcode is used for Apple-platform development. Final review and responsibility remain with Schrotty74.

Complete feature list

01Choose which recognised Apple Health data types appear in the app
02Interactive 7-day, 30-day, 3-month and 1-year trend views
03Favourites, categories, search and local drag-and-drop card ordering
04Shared multi-metric timeline, rings, calendars and descriptive local patterns
05Locally written PDF report only at a user-selected location
06Import an Export.xml file or ZIP archive selected by the user
07Configurable health-data cards
08Date ranges and interactive detail views
09Local categories, favourites and search
10Session-only handling with an empty start and end state

Data and privacy

There are no accounts, analytics, advertising, tracking or cloud uploads. Imported health data stays in memory for the current session; no direct HealthKit or cloud-service connection is used.

Descriptions, technical information, downloads and manuals are based on the publicly available repository. Links open the selected external service only after you activate them. Where screenshots are displayed, the repository documents them as demo or fictional data.
