UroBilanz

Local analysis for urine and fluid records.

View on GitHub ↗Technical details →
Beta 1.7.4

What it does

UroBilanz is a private diary and analysis tool for urine output, fluid intake and notes. It can import and merge Urinote CSV files, accepts manual entries and turns the data into day, week, month and year views. It is an aid for recording and review, not a medical diagnostic or recommendation tool.

AI-assisted development

Developed by Schrotty74 with AI assistance. Depending on the project, OpenAI Codex and, in parts, Claude supported development work; Xcode is used for Apple-platform development. Final review and responsibility remain with Schrotty74.

Complete feature list

01Import, merge and edit urine, water and note entries
02Totals, averages, flags and streaks across several time ranges
03Notes stay connected to their matching time or remain visible as general notes
04Selectable medical report with daily detail and evaluation rules
05Complete backup plus CSV, JSON and macOS PDF export
06Adjustable column widths saved locally
07Importable, exportable and removable custom themes
08Selectable report period with summary, daily progress and notes
