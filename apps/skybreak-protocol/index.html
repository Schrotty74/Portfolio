Skybreak Protocol

A cyberpunk arcade ascent across fourteen levels.

View on GitHub ↗Start web app ↗Technical details →
Beta 1.0.1

What it does

Skybreak Protocol is a vertical cyberpunk arcade game for desktop and mobile browsers. You guide a climbing robot through fourteen different 15-floor environments, break routes open with an ice pick, avoid drones and hazards, and progress to a distinct boss arena in every sector. Difficulty, visual style and ice-pick upgrades let each run change while progress remains on the device.

AI-assisted development

Developed by Schrotty74 with AI assistance. Depending on the project, OpenAI Codex and, in parts, Claude supported development work; Xcode is used for Apple-platform development. Final review and responsibility remain with Schrotty74.
