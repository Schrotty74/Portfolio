ThermalAtlas

Local temperature monitor for Apple Silicon.

View on GitHub ↗Technical details →
1.0.0

What it does

ThermalAtlas is a lightweight read-only menu bar monitor for Apple Silicon Macs. It shows actual CPU, GPU, internal SSD and physical external SSD values when macOS exposes them, and clearly says “Not available” instead of estimating. It is designed for monitoring rather than controlling fans, power settings or other hardware behaviour.

AI-assisted development

Developed by Schrotty74 with AI assistance. Depending on the project, OpenAI Codex and, in parts, Claude supported development work; Xcode is used for Apple-platform development. Final review and responsibility remain with Schrotty74.

Complete feature list

01CPU, GPU, internal SSD and physical external SSD sensor monitoring
02SMART status and SSD health where macOS supplies the values
03Local history, optional temperature alerts and export on request
04Standard and Compact view, selectable sensor groups and menu-bar modes
05Four native themes and optional German display language
06Two-second refresh by default, adjustable from one to four seconds
07Shows Not available instead of estimating a missing sensor
08Read-only CPU/GPU load and memory context
09Physical external SSDs shown separately when available
10Independent drive refresh cycles so slow drive queries do not delay CPU/GPU values
11Snapshot or CSV export only after a user choice
12No fan, power or system-setting control

Data and privacy

The app works offline without accounts, telemetry, analytics or network communication. It requires no administrator or root access and reads only sensor data exposed by macOS.
