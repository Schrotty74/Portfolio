What it does

BudgetAtlas is a responsive household-budget PWA for desktop and mobile. It presents income, expenses and the available monthly buffer in a focused dashboard, while keeping everyday entry and correction work close at hand. It supports exports and a preview-based backup restore, so the user controls where the financial data goes.

AI-assisted development

Developed by Schrotty74 with AI assistance. Depending on the project, OpenAI Codex and, in parts, Claude supported development work; Xcode is used for Apple-platform development. Final review and responsibility remain with Schrotty74.

Complete feature list

01Create, edit and delete income and expense entries
02Animated expense mix and percentage views
03Excel import with preview and invalid-row feedback
04Excel, PDF, PNG and JSON export plus previewed backup restore
05Offline PWA with desktop sidebar, mobile navigation and reduced-motion support
06Swipe-to-delete with undo on mobile
07Collapsible income and expense sections
08Select 10–25 entries per page for income and expenses
09Dark and light mode
10Desktop sidebar and mobile bottom navigation
11Update notice through version.json

Data and privacy

Budget data is stored exclusively in the browser’s localStorage. There is no account, tracking or server-side storage of personal financial data.
