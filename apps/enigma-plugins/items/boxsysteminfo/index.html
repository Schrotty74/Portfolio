Project description

Box Systeminfo displays receiver, storage, temperature and image information on an Enigma2 screen. Author: Schrotty74. It targets open Enigma2 images such as OpenPLi and OpenATV on ARMv7 receivers. Version 0.1.11 was tested successfully by the user and approved for publication.

Features and details

01Customizable overview: three saved cards chosen from temperatures, RAM, root storage, recording storage and network. Selecting an existing card swaps its position.
02Four themes: Midnight, Ocean, Amber and Light, with the selection saved.
03Receiver and image: model, CPU, architecture, uptime, image name/version, build/date, Enigma2, kernel and Python versions.
04SSD and SMART: temperature, model, health, power-on hours, supported error counters, reserve space and write totals; remaining lifetime only for an unambiguous supported percentage attribute.
05Recording storage: capacity, used/free space, usage percentage, mount point and read-only status.
06CPU: online cores, current/maximum frequency and 1/5/15-minute load averages.
07Network: interface type, connection status, negotiated link speed and receive/send rates in Mbit/s.
08Active DVB tuner: signal quality in dB or relative percent, AGC, BER and lock, plus detected frontend use and recording counts.
09History charts: ten-minute temperature and network-rate curves held only in session RAM and cleared on closing.
10Refresh options: manual OK refresh or automatic Off/2/5/10/30-second intervals; default 5 seconds. Automatic SMART reads at most once per minute.
11Left/Right or Green: change theme. Midnight, Ocean, Amber, and Light are available, and the selection is saved.
12OK: refresh values.
13Exit or Red: close the plugin.
14Yellow or Blue: open details.
