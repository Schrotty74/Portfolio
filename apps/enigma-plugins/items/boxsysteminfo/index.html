Project description

Box Systeminfo displays receiver, storage, temperature, and image information on an Enigma2 screen. The author is Schrotty74. It targets open Enigma2 images such as OpenPLi and OpenATV on ARMv7 receivers. Version 0.1.9 was tested on the user's receiver; the user confirmed that the data is now displayed and approved publication of the IPK.

Features and details

01Left/Right or Green: change theme. Midnight, Ocean, Amber, and Light are available, and the selection is saved.
02OK: refresh values.
03Exit or Red: close the plugin.
04Yellow or Blue: open details.
05In details, Up/Down or Yellow/Blue moves between storage/SSD, CPU, network, and tuner pages. Exit returns to the main overview.
06Menu: open help.
07Recording storage: capacity, used and free space, percent used, and mount point. The configured recording path takes precedence. If none is configured, the plugin uses an Enigma2-mounted partition only when it finds exactly one candidate; it leaves the path unset when several candidates are ambiguous. An unmounted recording directory is not reported as a recording disk.
08Storage checks run in a separate Python process with a three-second timeout so a slow network filesystem cannot block the interface.
09CPU: online core count, current and maximum clock where available, and load averages over 1, 5, and 15 minutes. Load averages are not CPU-use percentages.
10Network: interface, type, connection state, and negotiated link speed when the driver exports it. No Internet query is made. IP and MAC addresses are not display fields.
11Tuners: configured frontends and detected active use. FBC tuners can expose virtual frontends. An unobserved frontend is not reported as free. The recording count uses a real-recording filter where available; the timer-list fallback is labelled as such.
12Warnings: SoC temperature from 80 °C, drive temperature from 60 °C, and storage use from 90%. SMART failures and read-only recording storage are also highlighted. These are notification thresholds, not manufacturer limits.
