What it does

CodexVault creates verified local backups for selected work folders, Codex-related data and ChatGPT exports. It previews sources, checks the backup destination, creates ZIP archives and restores selected items into new folders so existing data is not overwritten. Backup profiles and the archive view support repeated local backup work.

AI-assisted development

Schrotty74 develops these projects with AI assistance. Depending on the project, OpenAI Codex and, in parts, Claude support the development work. Xcode is used for Apple-platform development. Schrotty74 retains final review and responsibility.

Data and privacy

CodexVault works locally and does not upload data or run silent backups. Normal backups exclude typical secrets and build artefacts; complete backups can contain sensitive local Codex data and should be stored only in a trusted destination.
