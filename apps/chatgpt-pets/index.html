Collection

What it does

ChatGPT Pets is a collection of custom animated companions that can be imported into ChatGPT and Codex. Each character is presented in its own folder with a preview and an importable sprite-sheet file. The collection currently includes Woodi, WonderCube, Delta, Byte, Whiskers & Squeak, Inky and Finder Guy.

AI-assisted development

Developed by Schrotty74 with AI assistance. Depending on the project, OpenAI Codex and, in parts, Claude supported development work; Xcode is used for Apple-platform development. Final review and responsibility remain with Schrotty74.

Data and privacy

This repository is an asset collection. Import happens through the respective ChatGPT or Codex pet manager; the repository README does not document an independent app account, analytics or telemetry service.

Descriptions, technical information, downloads and manuals are based on the publicly available repository. Links open the selected external service only after you activate them. Where screenshots are displayed, the repository documents them as demo or fictional data.
