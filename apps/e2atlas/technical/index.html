Technical details

e2Atlas

Platform and architecture

Native macOS application built with SwiftUI and Liquid Glass controls. Requires Apple Silicon (M1 or later), macOS 26 or later, and an Enigma2 receiver with accessible OpenWebif and streaming services. Intel Macs are not supported.

Receiver connection and playback

Receivers are accessed through OpenWebif. Live TV, multiview with up to four streams, and receiver-recording playback use VLCKit 3.7.3. VideoToolbox decoding is requested where supported, with a possible software-decoding fallback. Hardware decoding and CPU impact have not been measured.

EPG, timers and local data

The seven-day electronic programme guide uses local caching, search, configurable refresh, reminders and receiver-side recording timers. EPGRefresh and AutoTimer require compatible receiver plugins. Local recordings save the original stream as a TS file. Receiver-specific settings and playback positions are stored locally; passwords use the macOS Keychain. Dev, Beta and Final keep their settings, caches and Keychain services separate.

Development, builds and licensing

The project uses SwiftUI, an Xcode project and a SwiftPM manifest. Scripts/generate-project.py regenerates the project file; Scripts/test.sh runs tests through Xcode. VLCKit downloads are SHA-256-verified. The app is licensed under GPLv3, while replaceable dynamic VLCKit is LGPL-2.1-or-later.

Installation and limitations

Beta builds are ad-hoc signed rather than notarized; macOS may require approval in Privacy & Security on first launch. HTTP receiver connections are not encrypted. Actual timer execution and wider receiver-image compatibility have not been fully confirmed.
