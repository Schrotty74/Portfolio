AppAtlas

Local software catalogue and organiser for macOS.

View on GitHub ↗Technical details →
Final

What it does

AppAtlas turns folders you select into a personal software catalogue. It indexes app entries, icons, descriptions, tags, links and licence information, then makes the collection searchable and exportable. Repeated scans can show what is new, changed or removed instead of silently changing the catalogue.

AI-assisted development

Developed by Schrotty74 with AI assistance. Depending on the project, OpenAI Codex and, in parts, Claude supported development work; Xcode is used for Apple-platform development. Final review and responsibility remain with Schrotty74.

Key features

01Read-only scans of selected folders with permanent folder and file-extension exclusions
02Compare new, changed and removed files on repeat scans
03Add, edit and delete app entries; move local app files to the Trash only after confirmation
04Tags, search across name, description, category, folder and tags, plus hierarchical categories
05Descriptions, links, high-quality local icons and fast thumbnails
06Explicit Homebrew and Setapp catalogue updates; update missing metadata
07Review uncertain matches and configure online lookups, processing and extended search locally
08Manage per-app website prompts, translate foreign-language descriptions locally and use the optional app assistant
09Import, export and delete themes; Liquid Glass on macOS 26+ with compatible rendering on older systems
10JSON catalogue import/export, optional licence-data exclusion and AES-256-GCM password protection
11Export reminders, catalogue statistics, licence import and private licence storage in the macOS Keychain
12Delete the complete catalogue when required, create privacy-conscious bug reports and use English or German

Data and privacy

Normal scans do not contact online services. Licence data can be kept in the macOS Keychain; online catalogue lookup is optional and initiated by the user.

Descriptions, technical information, downloads and manuals are based on the publicly available repository. Links open the selected external service only after you activate them. Where screenshots are displayed, the repository documents them as demo or fictional data.
