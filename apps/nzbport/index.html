NZBPort

Menu bar app for nzblnk: links and SABnzbd.

View on GitHub ↗Technical details →
0.1.1

What it does

NZBPort opens nzblnk: links from Safari and submits matching NZB downloads to SABnzbd after you choose a category. It searches NZBIndex with NZBKing and BinSearch as fallbacks and remains available in the macOS menu bar after submission.

AI-assisted development

Schrotty74 develops these projects with AI assistance. Depending on the project, OpenAI Codex and, in parts, Claude support development. Xcode is used for Apple-platform development. Schrotty74 retains final review and responsibility.

Complete feature list

01Open nzblnk: links from Safari or paste from clipboard
02Select a SABnzbd category before sending a download
03Search NZBIndex, then NZBKing and BinSearch when needed
04Pass link title and optional unpack password to SABnzbd
05Automatically refresh SABnzbd categories and manually refresh in settings
06Hide categories locally without changing the SABnzbd server
07Display connection and submission errors
08Handle multiple links in sequence from the menu bar
09Switch between English, German and system language
10Choose Standard, Coffee, Ivory or Mint themes
11Native Liquid Glass controls and adaptive app icon
12Launch at Login through macOS login items
13Open the GitHub project and portfolio from About NZBPort
14Swift app using Apple system frameworks without third-party packages

Data and privacy

The SABnzbd URL and API key are stored locally in app preferences without encryption, not in Keychain. HTTP connections are unencrypted; use HTTPS or a trusted VPN on untrusted networks. External search services receive search identifiers but not your SABnzbd API key.

Requires macOS 26 or later on Apple Silicon, plus a SABnzbd server and API key. Builds are ad-hoc signed and not notarized.
