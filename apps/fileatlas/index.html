FileAtlas

File indexer, duplicate finder and folder comparison.

View on GitHub ↗Technical details →
1.9

What it does

FileAtlas helps inspect larger local file collections without sending their contents away. It can index chosen folders, compare saved snapshots, identify duplicates and create reports or backups. Its focus is on making storage, metadata and changes understandable before you decide what to remove or keep.

AI-assisted development

Developed by Schrotty74 with AI assistance. Depending on the project, OpenAI Codex and, in parts, Claude supported development work; Xcode is used for Apple-platform development. Final review and responsibility remain with Schrotty74.

Complete feature list

01Recursive multi-folder indexing with live progress and persisted folder permission
02QuickLook preview, metadata inspection and powerful size or extension search
03Duplicate detection via size grouping and SHA-256 hashes
04Up to ten JSON snapshots per location with change summaries and comparison
05Reports, storage analysis, verified backups and safe batch rename with preview
06Persistent access to selected folders
07Metadata-based filtering, extension and size searches
08QuickLook previews
09Storage analysis and report exports
10Safe batch rename with preview
11Optional GitHub Releases update check
