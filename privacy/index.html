2. Scope and purpose

This website presents independent software projects. It does not provide accounts, a contact form, comments, uploads or payments.

3. Hosting via GitHub Pages

This static website is published through GitHub Pages. When you access the website, GitHub processes technically necessary connection and usage data under its own privacy statement. The site operator does not operate separate visitor logs. The legal basis for providing this website is Art. 6(1)(f) GDPR; the legitimate interest is a secure and reliable public project presentation.

4. Project preview images

Project preview images are loaded directly from GitHub’s public raw-content domain. Your browser therefore connects to GitHub when a preview image is displayed.

5. No own cookies, analytics or advertising

This website itself does not set cookies, use browser storage, run analytics, advertising trackers, marketing pixels or contact forms, and does not create visitor profiles. The selected colour theme applies only for the current visit and is not stored.

6. AI assistance during development

AI assistance is used during the development of the listed projects. The website itself does not offer an AI system, chatbot or automated decision-making and does not send visitor-provided data to AI tools.

7. External links

Links to GitHub and individual project pages are activated only when you select them. The privacy policies of the respective providers apply after leaving this website.

8. Your rights

Subject to the legal requirements, you have rights of access, rectification, erasure, restriction, data portability and objection. You also have the right to lodge a complaint with a data protection authority. In Austria, this is the Austrian Data Protection Authority. Please use the public project profile above for contact.

9. Changes

This policy is updated if the website's functions, integrated services or legal requirements change.
